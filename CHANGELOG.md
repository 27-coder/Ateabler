# Changelog

## 0.1.0 — Unreleased preview

- Admin controls remote download jobs while workers use their own disk and network.
- Bulk collection supports direct HTTP(S), yt-dlp media, and S3-compatible object/prefix inputs.
- Linux workers can be provisioned and paired over SSH; Windows/macOS workers use manual installation.
- Buckets save URL lists, with Firefox/Chrome/Edge capture and duplicate-safe dispatch.
- Scoped workspaces provide file logs, Node GUI/CLI access and Speaking messages.
- Admin, Node and browser capture use black backgrounds.
- Native and source installation packs cover the documented platform targets.

This is an unsigned preview. Broader provider, distro and desktop validation remains pending. See [PRODUCT.md](PRODUCT.md), [PACKAGING.md](PACKAGING.md) and [LINUX-COMPATIBILITY.md](LINUX-COMPATIBILITY.md) for tested boundaries.
