Choose your capture bucket

Save links while you browse. Start their downloads later in Ateable Admin; the files stay on your download computer.

  1. Open Ateable Admin on this computer.
  2. Go to Buckets, choose Inbox or another bucket, then click Browser capture….
  3. Copy the bucket's capture token from that dialog, paste it below, and verify the destination.
  4. Right-click a link or media item → Ate it on bucket. In Admin, use Download saved links when ready.

HTTP loopback only: 127.0.0.1, localhost, or [::1]. Enter an origin, without a path. The controller must run on this browser's computer.

What does the extension share?

Your explicit capture actions send selected URLs, optional titles and source-page URLs to Admin on this computer. The token authenticates those requests and stays in this browser's local extension storage. Firefox's data permissions disclose this token and the selected URL/page metadata. There is no history monitoring, background page scanning or media downloading. Page scans only read links in the current document; cross-origin frames, closed shadow roots, streaming manifests and undisclosed media URLs are not inspected.
